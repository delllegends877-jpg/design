# PROJECT: CREATIVE MARKETPLACE APP

Act as a senior UI/UX designer, Android app developer, backend engineer and product architect.

Build a complete, modern, professional Graphic Design Marketplace Android application.

## 1. App Concept
Create a platform where graphic designers can sell their creative services and clients can hire designers directly.

App Name: Creative Market BD
Platform: Android APK
Target Market: Bangladesh
Language: Bengali + English
Currency: BDT (৳)

## 2. User Roles
Create three user roles:

1. Client
2. Graphic Designer / Seller
3. Admin

## 3. Client Features
- User registration and login
- Browse graphic design services
- Search designers and services
- Filter by category, price and rating
- View designer profiles
- View portfolios and previous work
- Place orders
- Upload project requirements
- Chat with designers
- Track order progress
- Review and rate completed orders
- Order history
- Wishlist / Favorite designers

## 4. Designer Features
- Create professional seller profile
- Upload profile picture and portfolio
- Add design services
- Upload service thumbnails
- Set pricing and delivery time
- Create Basic, Standard and Premium packages
- Receive client orders
- Accept or reject orders
- Chat with clients
- Upload completed designs
- Manage revisions
- View earnings and order statistics

## 5. Marketplace Categories
Include these categories:

- Logo Design
- Brand Identity
- Social Media Design
- YouTube Thumbnail
- Business Card
- Flyer & Poster
- Packaging Design
- T-shirt Design
- Banner Design
- UI/UX Design
- Brochure Design
- Photo Editing

## 6. Admin Dashboard
- Manage users
- Approve designer profiles
- Manage services
- Manage categories
- Monitor orders
- Handle complaints
- Manage reviews
- View platform statistics
- Manage commissions
- Suspend fraudulent accounts

## 7. UI/UX Design
Design a premium, modern mobile interface.

Color Palette:
- Primary: Deep Navy Blue

Typography:

Design Style:

- Modern marketplace cards

## 9. Backend & Database
Use a secure backend with:
- User authentication
- Role-based permissions
- Database for users and services
- Order management
- Image and file uploads
- Real-time chat
- Notification system
- Secure API endpoints

Suggested technology:
- Flutter for Android application
- Supabase or Firebase for backend
- PostgreSQL or Firestore database

## 10. Payment System
Support:
- bKash
- Nagad
- Rocket
- Bank transfer

Implement payment gateway integration only through verified providers. Never simulate successful payments.

## 11. Security
- Secure authentication
- Password encryption
- Protected user data
- Role-based access control
- Secure file uploads
- Payment verification
- Order dispute management

## 12. Final Deliverables
- Complete Android application
- Functional backend
- Database schema
- Admin dashboard
- Designer dashboard
- Client dashboard
- Complete source code
- APK build instructions
- Testing and deployment documentation

IMPORTANT:
Do not create only a UI prototype. Build a functional marketplace with real database operations, authentication, order management, and properly integrated backend services.

All buttons and navigation must work. Do not use fake users, fake orders, fake payment confirmations or placeholder functionality in the production build.
